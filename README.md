# cs463-project

A program that, when run on separate devices, simulates sending messages to each other using the Diffie-Hellman Key Exchange. It will display to the user all of the information known to the computer, showing what is happening when devices use the Diffie-Hellman Key Exchange method for security. This could potentially serve as an interactive educational program, showing the Diffie-Hellman Key Exchange being used in action. It can be a sort of hands-on teaching method.
